# Crispy Shift 🍗

เกมบริหารร้านไก่ทอดบนเว็บ 2 วัน วันละ 3 นาที เป้าหมายเสิร์ฟวันละ 5 ออเดอร์ มีรายรับ ต้นทุน กำไร ความอดทนลูกค้า และทิป

## เริ่มเล่น

Node.js 22.12+ และ npm (ทดสอบด้วย Node 24)

```sh
npm ci
npm run dev
```

เปิดที่อยู่ที่ Vite แสดงในเครื่องที่รัน (พอร์ต 5173) แล้วกดเปิดร้าน

## เล่นในฉากร้าน

ออเดอร์สุ่มจาก 5 ชุดเมนูเดิมแบบใช้ให้ครบก่อนเริ่มรอบใหม่ ไม่ซ้ำติดกันข้ามรอบ และไม่ซ้ำกับลูกค้าที่ยังรออยู่ ชื่อลูกค้าสุ่มและไม่ซ้ำในคิว ถ้าสูตรที่เหลือในรอบถูกสั่งค้างอยู่ จะรอก่อนเพิ่มลูกค้าแทนการสั่งซ้ำ

1. ดูชื่อและรูปอาหารเหนือหัว คลิกตัวลูกค้าหรือป้ายเพื่อรับออเดอร์ จะมีเครื่องหมายถูก กรอบสีส้มแสดงคนที่เลือกเพื่อเสิร์ฟ
2. คลิกสถานีไก่ ฟรายส์ หรือน้ำซ้ำเพื่อเพิ่มคิว อาหารทำ **ทีละชิ้นต่อสถานี** และต่อชิ้นถัดไปอัตโนมัติ แต่ละสถานีทำพร้อมกันได้
3. วงคูลดาวน์และตัวเลขแสดงเวลาของชิ้นปัจจุบัน ตัวเลขคิวรวมชิ้นที่กำลังทำและรออยู่ จุดแสดงจำนวนคิว
4. อาหารที่เสร็จเด้งไปช่องจริงในตู้ มีช่องชนิดละ 5 ช่อง คลิกอาหารในตู้เพื่อหยิบลงถาด
5. จัดถาดตรงออเดอร์คนที่เลือก ถาดจะขึ้นสีเขียว คลิกบริเวณถาด ขอบ หรือกองถาดเพื่อเสิร์ฟ คืนอาหารทั้งถาดได้ด้วยปุ่มใต้ถาดซึ่งแยกจากพื้นที่เสิร์ฟ

ไม่มีแผงออเดอร์ด้านขวา แนวบริการเรียงจากแคชเชียร์ → ถาดขอบเตี้ยซ้อนกัน → ตู้อุ่นอาหารกระจก ส่วนครัวร้อนกะทัดรัดอยู่แนวด้านล่าง กรอบเกมย่อพอดีทั้งความกว้างและความสูงของหน้าจอ เห็นหน้าร้านและครัวครบในหน้าเดียว ไม่ต้องเลื่อนฉากหรือหน้าเว็บ รายละเอียดจะเล็กลงตามสเกลบนจอเล็ก

| ปุ่ม | การทำงาน |
|---|---|
| Tab | เลือกลูกค้าถัดไป |
| E | รับออเดอร์ที่เลือก |
| 1 / 2 / 3 | เพิ่มคิวไก่ / ฟรายส์ / น้ำ |
| Q / W / R | หยิบไก่ / ฟรายส์ / น้ำจากตู้ลงถาด |
| Enter | เสิร์ฟถาดให้ลูกค้าที่เลือก |
| Backspace | คืนอาหารทั้งถาดเข้าตู้ |
| Space | พัก / เล่นต่อ |

## พนักงาน เวลาเปิดร้าน และรายได้ประจำวัน

- นาฬิกาอยู่ภายในฉากร้าน แสดงเวลาเปิด 10:00 ปิด 22:00 ย่อ 12 ชั่วโมงในร้านเป็นเวลาเล่น 3 นาที เวลาในร้านหยุดขณะพักเกม
- พนักงานตามภาพอ้างอิง สวมหมวกแก๊ปแดง เสื้อเชิ้ตขาว ผ้ากันเปื้อนแดงพร้อมกระเป๋าเครื่องมือ และกางเกงดำ มีมุมหน้า ด้านข้างซ้าย–ขวา และด้านหลังตามทิศทางเดิน และรอข้างแคชเชียร์ เดินตามคิวงานไปสถานีทำอาหาร ตู้เก็บอาหาร และถาด ผ่านทางเดินหลังแนวบริการ แล้วกลับแคชเชียร์เมื่อว่าง
- การเดินเป็นภาพประกอบคำสั่ง: คิวอาหารและการคิดเงินเริ่มทันที ไม่ต้องรอเดินถึง และการกดซ้ำไม่ข้ามงานเดินที่สั่งไว้
- เมื่อเข้าคิวทำอาหารสำเร็จ จะแสดงเงินลอยสีแดงตามต้นทุนจริง เสิร์ฟสำเร็จแสดงเงินลอยสีเขียวรวมทิป คิวเต็มหรือถาดผิดไม่คิดเงินซ้ำ
- ยอดวันนี้แสดงรายรับ วัตถุดิบ และกำไร เมื่อเวลา 22:00 แสดงสรุปประจำวัน รวมต้นทุนอาหารที่ยังเหลือหรือยังทำไม่เสร็จ
- ปุ่มหยุดเกมอยู่มุมขวาบนและเลื่อนตามหน้าจอ หยุดเวลา คิว ความอดทน การเดิน และเอฟเฟกต์ได้ เริ่มวันใหม่ล้างยอดและคิวงาน

## วันที่ 2 และการอัปเกรด

1. เล่นวันที่ 1 จนปิดร้าน 22:00 แล้วอ่านสรุปรายได้
2. กด **สรุปเรียบร้อย · เลือกอัปเกรดครัว** เพื่อกลับมาดูเครื่องทอดในร้านที่หยุดเวลาไว้
3. กดเครื่องหมาย **+** บนหม้อทอดไก่หรือหม้อทอดฟรายส์ เลือกฟรีได้ **อย่างใดอย่างหนึ่งเพียงครั้งเดียว**: ไก่ 5 → 4 วินาที หรือฟรายส์ 3 → 2 วินาทีต่อชิ้น
4. กด **เปิดร้านวันที่ 2** เครื่องที่เลือกมีป้าย ⚡ และใช้เวลาที่ลดแล้วทั้งชิ้นแรกและชิ้นต่อคิว เครื่องอีกชนิดและน้ำคงความเร็วเดิม
5. วันที่ 2 ลูกค้ารอได้ **44 วินาที** (จาก 55 ลด 20%) เกิดทุก **5.5 วินาที** หรือ **6.5 วินาที** เมื่อมีลูกค้าตั้งแต่ 2 คน ยังคงเติมลูกค้าทันทีเมื่อร้านว่างและไม่ให้ออเดอร์ซ้ำในคิว
6. จบวันที่ 2 จะแสดงสรุปวันนั้นและกำไรรวมสองวัน เริ่มใหม่จะกลับวันที่ 1 โดยไม่มีอัปเกรด

การขึ้นวันใหม่ล้างอาหารในตู้ ถาด คิวทำอาหาร คิวงานพนักงาน และยอดประจำวัน แต่เก็บใบสรุปวันที่ 1 ไว้ ไม่มีค่าอัปเกรดหรือเงื่อนไขยอดเงินเพิ่ม ยังไม่มีวันที่ 3 และรีเฟรชหน้าเว็บจะเริ่มใหม่

## ภาพร้านและอุปกรณ์

ตกแต่งโดยอิงบรรยากาศร้านไก่ทอดแดง–ขาวแบบ KFC พร้อมป้ายเมนูเหนือกระจก แถบเคาน์เตอร์แดง–ขาว ถังไก่ โปสเตอร์ ม้านั่งบูธ โคมไฟและจุดคืนถาด ใช้ภาพเวกเตอร์ชื่อ Crispy Shift ที่สร้างในโปรเจกต์ ไม่ต้องดาวน์โหลดรูปหรือฟอนต์ภายนอก

หน้าร้านเป็นกระจกบานใหญ่พร้อมกรอบ ประตูกระจก และแสงสะท้อน มองออกไปเห็นอาคาร ต้นไม้ รถและเส้นช่องจอด สีท้องฟ้า แสงเย็น แสงในร้าน และไฟลานจอดรถเปลี่ยนอย่างต่อเนื่องตามนาฬิกาเกม เมื่อพักเกมแสงคงเดิม นาฬิกาอยู่ในฉากที่ย่อพอดีหน้าจอ อุปกรณ์ปรับสัดส่วนให้กะทัดรัด โดยตู้อุ่นมีโครงสเตนเลส กระจกโค้ง รางชั้นและช่องระบายอากาศ ถาดซ้อนแสดงหลายใบแต่ยังใช้ถาดเสิร์ฟที่กำลังจัดเพียงใบเดียวตามเดิม

ร้านใช้ภาพ 2D โทนแดง–ขาวตัดดำ เพิ่มมิติด้วยหน้าวัตถุ เงาทอด ผิวสเตนเลสและกระจก เครื่องทอดไก่และฟรายส์เป็นชุดทอดอุตสาหกรรมอ่างคู่ มีตะแกรงยกพัก ด้ามจับแดง ฮูด ท่อดูดควัน เกจอุณหภูมิและตู้สเตนเลส วางเสมอขอบล่างของฉาก ส่วนตู้กดน้ำอยู่ด้านข้าง ทั้งหมดเป็นภาพ SVG ภายในโปรเจกต์ ไม่โหลดรูปภายนอก น้ำมันมีฟอง คลื่น และไอน้ำเฉพาะขณะทำอาหาร ตู้กดน้ำมีสายน้ำขณะทำงาน เอฟเฟกต์หยุดขณะพักหรือจบกะ และรองรับ reduced motion ตู้เก็บเป็นตู้อุ่นกระจก ส่วนถาดมีขอบแดงและกระดาษรอง

เมื่อเสิร์ฟถูกจะแสดง 😊 พร้อมชื่อลูกค้า แม้ลูกค้าออกจากคิวไปแล้ว ส่วนเสิร์ฟผิดจะแสดง 😡 อาหารในถาดและลูกค้ายังคงอยู่ ไม่มีรายรับหรือค่าปรับเพิ่ม เอฟเฟกต์หยุดตามการพักเกม และปุ่ม Enter ยังใช้เสิร์ฟได้

## จังหวะลูกค้าด่านแรก

- ด่านยาว 3 นาที: ช่วงห่างพื้นฐาน 6 วินาทีตลอดด่าน
- เมื่อลูกค้ารอตั้งแต่ 2 คน ใช้ช่วงห่างรวม 7 วินาที (ไม่ใช่บวกเพิ่ม 7 วินาที) จำกัดคิวสูงสุด 4 คนและไม่ให้ออเดอร์ซ้ำตามเดิม
- ถ้าเสิร์ฟคนสุดท้ายหรือหน้าร้านว่างเพราะลูกค้าออก จะเติมลูกค้าใหม่ 1 คนทันที และเริ่มนับช่วงห่างใหม่ ป้องกันเกิดซ้อนอีกคนติดกัน
- ระหว่างพักเกมหรือปิดร้านจะไม่เติมลูกค้าใหม่

## กติกาคิวและสต็อก

- ไก่ 5 วินาที ต้นทุน 18 บาท; ฟรายส์ 3 วินาที ต้นทุน 8 บาท; น้ำ 1 วินาที ต้นทุน 4 บาท ต่อชิ้น
- อาหารแต่ละชนิดมีได้รวม **5 ชิ้นนับคิว + ในตู้ + บนถาด** เพื่อไม่ให้ตู้ล้นและคืนของได้เสมอ เสิร์ฟแล้วจึงทำเพิ่มได้
- หักต้นทุนทันทีเมื่อรับเข้าคิว คิวเต็มไม่หักเงิน และกดเพิ่มไม่รีเซ็ตเวลาชิ้นที่กำลังทำ
- พักเกมหยุดทั้งเวลา ความอดทน และคิว เมื่อจบกะจะหยุดคิวที่เหลือ เริ่มใหม่ล้างคิวและสต็อก
- ลูกค้ารอได้ 55 วินาที เสิร์ฟตอนเหลือมากกว่า 30 วินาทีได้ทิป 10 บาท ถาดผิดไม่เสิร์ฟและไม่เสียของ

## ตรวจสอบ

```sh
npm test
npm run build
# เปิด dev server ก่อน แล้วใช้ terminal อีกอัน:
npm run test:tray # ตรวจคลิกค้างบนไอคอน ขอบ ข้อความ และกองถาด 10 จุด ทั้งจอคอมและขนาดมือถือ
npm run test:viewport # ตรวจเห็นฉากครบ 6 ขนาดจอและคลิกเล่นหลังย่อ
npm run test:kitchen # ตรวจครัวและคิว ~25 วินาที
npm run test:orders  # ตรวจหลายลูกค้า ~60 วินาที
npm run test:stage2 -- chicken --full # เล่นผ่านวัน 1 อัปเกรดไก่ และจบวัน 2 จริง ~6 นาที
npm run test:stage2 -- fries # จบวัน 1 อัปเกรดฟรายส์และทดสอบเล่นวัน 2 ~3 นาที
npm run test:browser # ครบวงจร รวมรอจบกะจริง ~3 นาที
```

Browser tests ใช้ Playwright กับ `/usr/bin/chromium` เก็บภาพ `artifacts/kitchen-*.png` ไม่รวมใน Git อย่าแก้ไฟล์แอประหว่างทดสอบ เพราะ Vite อาจรีโหลดและเริ่มกะใหม่ ใช้ `npm run preview` ดู production build หลัง build แล้ว

## โครงสร้าง

- `src/campaign.ts`: การต่อวัน สรุปวันแรก และสิทธิ์เลือกอัปเกรดครั้งเดียว
- `src/game.ts`: กฎเกม คิว สต็อก เหตุการณ์อาหาร และการเงิน แยกจากภาพ
- `src/main.ts`: ฉาก Phaser, ปุ่มในฉาก, HUD, input และ animation ย้ายอาหาร
- `src/decor.ts`: ภาพป้ายเมนู ถังไก่ บูธและของตกแต่งร้าน
- `src/storefront.ts`: ภาพหน้ากระจก ลานจอดรถ ตู้อุ่นอาหาร และแสงตามเวลา
- `src/worker-art.ts`: ภาพพนักงานหมวกแก๊ปและผ้ากันเปื้อนแดงตามภาพอ้างอิง หลายทิศทาง
- `src/employee.ts`: คิวการเดิน จุดทำงาน และเส้นทางอ้อมตู้
- `src/industrial-fryer.ts`: ภาพเครื่องทอดอุตสาหกรรมอ่างคู่และฮูด อิงรูปตัวอย่างให้เข้ากับมุมมองเกม
- `src/equipment.ts`: ภาพเวกเตอร์หม้อทอด ตะแกรงทอด และตู้กดน้ำ
- `src/style.css`: ธีมร้าน ฉากและปุ่ม responsive
- `tests/`: unit และ browser tests

ไม่มีบริการภายนอกระหว่างเล่น ยังไม่มีเสียงหรือระบบเซฟ รองรับ 2 วันและอัปเกรดเครื่องทอด 1 อย่างระหว่างวัน รีเฟรชเริ่มใหม่ Build ยังมีคำเตือน bundle ของ Phaser (~340 KB gzip)

### หน้าเริ่มเกม
หน้าแรกใช้ภาพมาสคอตการ์ตูนใหม่ใน `public/splash.webp` อ้างอิงหมวกไก่ ผมแดง และชุดถังไก่จากภาพตัวอย่างของผู้ใช้ ปุ่มเริ่มกะเปิดวันที่ 1 ตามเดิม มีวิธีเล่นแบบพับเก็บ และปรับเลย์เอาท์สำหรับคอมพิวเตอร์กับมือถือ

### ลูกค้าพิเศษ เบิร์ด
สุ่มเกิดประมาณ 5% ต่อรอบการเกิดลูกค้าในทั้งสองวัน (มีเบิร์ดรอได้ครั้งละคน) สั่งอาหารสุ่มรวม 6 ชิ้นจากไก่ ฟรายส์ และน้ำ โดยแต่ละชนิดไม่เกิน 5 ชิ้นให้ทำได้ภายใต้ความจุเดิม ป้ายเหนือหัวรวมอาหารชนิดเดียวกันพร้อมจำนวน เช่น 🍗×3 เบิร์ดมีเวลารอครึ่งหนึ่งของลูกค้าปกติ (วันที่ 1: 27.5 วินาที / วันที่ 2: 22 วินาที) เสิร์ฟถูกได้เงิน 2 เท่าของค่าอาหาร ไม่รวมทิป หากเสิร์ฟผิด รอหมดเวลา หรือปิดร้านโดยยังไม่เสิร์ฟ จะถูกปรับเท่าค่าอาหาร 1 เท่า โดยหักครั้งเดียวต่อออเดอร์แม้คลิกผิดซ้ำ ยังสามารถแก้ถาดและเสิร์ฟใหม่ได้ ค่าปรับแสดงแยกในสรุปและหักจากกำไร

### นาบีเดินป่วนร้าน
ทุก 10 ออเดอร์ที่เสิร์ฟสำเร็จในแต่ละสเตจ (10, 20, 30, …) นาบีจะเดินผ่านกลางร้านด้านหน้าอุปกรณ์ วนไปมา และออกจากร้านในเวลาเกม 8 วินาที ตัวละครมีขนาดใกล้เคียงพนักงานพร้อมป้ายชื่อและแถบแจ้งเตือนเด่นชัด ไม่สั่งอาหาร ไม่ใช้ช่องลูกค้า ไม่กระทบยอดเงินหรือจำนวนลูกค้าที่ออก และไม่ขวางการคลิก เมื่อพักเกมนาบีหยุดด้วย เมื่อปิดร้านจะจบการเดิน และเริ่มนับใหม่ในวันถัดไป หากเสิร์ฟถึงรอบใหม่ขณะนาบียังอยู่ จะเข้ามาอีกครั้งหลังรอบก่อนจบ

ตรวจ flow การปรากฏจริงด้วย `node tests/nabi.mjs` หลังเปิด dev server โดยทดสอบเสิร์ฟ 10 ออเดอร์ด้วยการคลิกจริง การเดิน การพักเกม ภาพบนมือถือ และการออกจากร้าน
