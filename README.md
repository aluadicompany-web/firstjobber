# Crispy Shift 🍗

เกมบริหารร้านไก่ทอดบนเว็บ เวอร์ชันแรก: กะ 3 นาที รับออเดอร์ ทำอาหาร จัดถาด เสิร์ฟ และสรุปรายรับ/ต้นทุน/กำไร เป้าหมาย 5 ออเดอร์

## เริ่มเล่น

ต้องมี Node.js 22.12+ (ทดสอบด้วย 24) และ npm

```sh
npm ci
npm run dev
```

เปิดที่อยู่ที่ Vite แสดงในเครื่องที่รัน (พอร์ต 5173) กดเปิดร้าน เลือกลูกค้า แล้วรับออเดอร์ ทำอาหาร รอให้เสร็จ เพิ่มลงถาด และเสิร์ฟให้ตรงรายการ

| ปุ่ม | การทำงาน |
|---|---|
| เมาส์ | คลิกลูกค้าในร้าน/ใบออเดอร์ และปุ่มครัว |
| Tab | เลือกลูกค้าถัดไป |
| E | รับออเดอร์ที่เลือก |
| 1 / 2 / 3 | ทำไก่ / ฟรายส์ / น้ำ |
| Q / W / R | เพิ่มไก่ / ฟรายส์ / น้ำลงถาด |
| Enter | เสิร์ฟ |
| Backspace | คืนอาหารจากถาดเข้าสต็อก |
| Space | พัก / เล่นต่อ |

เวลาทำอาหาร 5/3/1 วินาที ต้นทุนคิดทันทีเมื่อเริ่มทำ ลูกค้ารอได้ 55 วินาที เสิร์ฟขณะเหลือความอดทนมากกว่า 30 วินาทีได้ทิป 10 บาท อาหารผิดไม่เสียของ แต่ต้องคืนแล้วจัดถาดใหม่ เกมหยุดเมื่อเปลี่ยนไปแท็บเบราว์เซอร์อื่นตามพฤติกรรม Phaser

## ตรวจสอบ

```sh
npm test
npm run build
# รัน dev server ก่อน แล้วอีก terminal:
npm run test:browser
```

Browser test ใช้ Playwright และ Chromium ที่ `/usr/bin/chromium` เก็บภาพที่ `artifacts/` ซึ่งไม่รวมใน Git ตรวจวงจรรับ/ทำ/เสิร์ฟ กำไร ปุ่มลัด พักเกม จบกะ เริ่มใหม่ และความกว้างมือถือ

`npm run preview` ใช้ดู production build หลัง build แล้ว

## โครงสร้าง

- `src/game.ts`: กฎเกมและสถานะแยกจากภาพ
- `src/main.ts`: Phaser scene, DOM HUD และ input
- `src/style.css`: ธีมร้านสีเขียว/ครีมและ responsive layout
- `tests/`: unit tests และ browser flow

ภาพวาดด้วย Phaser ไม่ใช้บริการภายนอกระหว่างเล่น ไม่มีเสียง ระบบเซฟ อัปเกรดร้าน หรือหลายวันในเวอร์ชันนี้ รีเฟรชแล้วเริ่มใหม่ Build มีคำเตือน bundle ใหญ่จาก Phaser (~339 KB gzip) ยังไม่ได้ปรับแบ่งโหลด
