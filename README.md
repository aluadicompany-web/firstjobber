# Crispy Shift 🍗

เกมบริหารร้านไก่ทอดบนเว็บ กะ 3 นาที เป้าหมายเสิร์ฟ 5 ออเดอร์ มีรายรับ ต้นทุน กำไร ความอดทนลูกค้า และทิป

## เริ่มเล่น

Node.js 22.12+ และ npm (ทดสอบด้วย Node 24)

```sh
npm ci
npm run dev
```

เปิดที่อยู่ที่ Vite แสดงในเครื่องที่รัน (พอร์ต 5173) แล้วกดเปิดร้าน

## เล่นในฉากร้าน

1. ดูชื่อและรูปอาหารเหนือหัว คลิกตัวลูกค้าหรือป้ายเพื่อรับออเดอร์ จะมีเครื่องหมายถูก กรอบสีส้มแสดงคนที่เลือกเพื่อเสิร์ฟ
2. คลิกสถานีไก่ ฟรายส์ หรือน้ำซ้ำเพื่อเพิ่มคิว อาหารทำ **ทีละชิ้นต่อสถานี** และต่อชิ้นถัดไปอัตโนมัติ แต่ละสถานีทำพร้อมกันได้
3. วงคูลดาวน์และตัวเลขแสดงเวลาของชิ้นปัจจุบัน ตัวเลขคิวรวมชิ้นที่กำลังทำและรออยู่ จุดแสดงจำนวนคิว
4. อาหารที่เสร็จเด้งไปช่องจริงในตู้ มีช่องชนิดละ 5 ช่อง คลิกอาหารในตู้เพื่อหยิบลงถาด
5. จัดถาดตรงออเดอร์คนที่เลือก ถาดจะขึ้นสีเขียว คลิกถาดเพื่อเสิร์ฟ คืนอาหารทั้งถาดได้ด้วยปุ่มใต้ถาด

ไม่มีแผงออเดอร์ด้านขวา ทุกอย่างอยู่ในร้าน จอแคบเลื่อนฉากซ้าย–ขวาได้เพื่อให้ปุ่มและอาหารมีขนาดอ่านและคลิกได้

| ปุ่ม | การทำงาน |
|---|---|
| Tab | เลือกลูกค้าถัดไป |
| E | รับออเดอร์ที่เลือก |
| 1 / 2 / 3 | เพิ่มคิวไก่ / ฟรายส์ / น้ำ |
| Q / W / R | หยิบไก่ / ฟรายส์ / น้ำจากตู้ลงถาด |
| Enter | เสิร์ฟถาดให้ลูกค้าที่เลือก |
| Backspace | คืนอาหารทั้งถาดเข้าตู้ |
| Space | พัก / เล่นต่อ |

## ภาพร้านและอุปกรณ์

ร้านใช้ภาพ 2D โทนแดง–ขาวตัดดำ เพิ่มมิติด้วยหน้าวัตถุ เงาทอด ผิวสเตนเลสและกระจก หม้อทอดไก่ ตะแกรงทอดฟรายส์ และตู้กดน้ำเป็นภาพ SVG ภายในโปรเจกต์ ไม่โหลดรูปภายนอก น้ำมันมีฟอง คลื่น และไอน้ำเฉพาะขณะทำอาหาร ตู้กดน้ำมีสายน้ำขณะทำงาน เอฟเฟกต์หยุดขณะพักหรือจบกะ และรองรับ reduced motion ตู้เก็บเป็นตู้อุ่นกระจก ส่วนถาดมีขอบแดงและกระดาษรอง

## กติกาคิวและสต็อก

- ไก่ 5 วินาที ต้นทุน 18 บาท; ฟรายส์ 3 วินาที ต้นทุน 8 บาท; น้ำ 1 วินาที ต้นทุน 4 บาท ต่อชิ้น
- อาหารแต่ละชนิดมีได้รวม **5 ชิ้นนับคิว + ในตู้ + บนถาด** เพื่อไม่ให้ตู้ล้นและคืนของได้เสมอ เสิร์ฟแล้วจึงทำเพิ่มได้
- หักต้นทุนทันทีเมื่อรับเข้าคิว คิวเต็มไม่หักเงิน และกดเพิ่มไม่รีเซ็ตเวลาชิ้นที่กำลังทำ
- พักเกมหยุดทั้งเวลา ความอดทน และคิว เมื่อจบกะจะหยุดคิวที่เหลือ เริ่มใหม่ล้างคิวและสต็อก
- ลูกค้ารอได้ 55 วินาที เสิร์ฟตอนเหลือมากกว่า 30 วินาทีได้ทิป 10 บาท ถาดผิดไม่เสิร์ฟและไม่เสียของ

## ตรวจสอบ

```sh
npm test
npm run build
# เปิด dev server ก่อน แล้วใช้ terminal อีกอัน:
npm run test:kitchen # ตรวจครัวและคิว ~25 วินาที
npm run test:orders  # ตรวจหลายลูกค้า ~35 วินาที
npm run test:browser # ครบวงจร รวมรอจบกะจริง ~3 นาที
```

Browser tests ใช้ Playwright กับ `/usr/bin/chromium` เก็บภาพ `artifacts/kitchen-*.png` ไม่รวมใน Git อย่าแก้ไฟล์แอประหว่างทดสอบ เพราะ Vite อาจรีโหลดและเริ่มกะใหม่ ใช้ `npm run preview` ดู production build หลัง build แล้ว

## โครงสร้าง

- `src/game.ts`: กฎเกม คิว สต็อก เหตุการณ์อาหาร และการเงิน แยกจากภาพ
- `src/main.ts`: ฉาก Phaser, ปุ่มในฉาก, HUD, input และ animation ย้ายอาหาร
- `src/equipment.ts`: ภาพเวกเตอร์หม้อทอด ตะแกรงทอด และตู้กดน้ำ
- `src/style.css`: ธีมร้าน ฉากและปุ่ม responsive
- `tests/`: unit และ browser tests

ไม่มีบริการภายนอกระหว่างเล่น ยังไม่มีเสียง ระบบเซฟ อัปเกรดร้าน หรือหลายวัน รีเฟรชเริ่มใหม่ Build ยังมีคำเตือน bundle ของ Phaser (~340 KB gzip)
